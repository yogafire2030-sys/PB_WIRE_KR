# Factor Factory — 롤링 멀티팩터 모델

지수 일간 수익률(종속변수)을 20여 개 후보 팩터(독립변수)로 **매일 다시 회귀**합니다.
t-검정과 F-검정을 모두 통과한 팩터만 채택하고, 그 결과를 가중치로 서서히 반영해
**"언제 어떤 팩터가 유의했는지"**를 추적하는 Flask 웹 대시보드입니다.

## 1. 설치·실행

```bash
cd factor_factory
python -m venv .venv
# Windows: .venv\Scripts\activate   /   macOS·Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 에 접속한 뒤 **오늘 업데이트**를 누릅니다.
첫 실행은 2016년 이후 데이터를 받느라 30초~1분 정도 걸립니다.

- 사내망에서 Yahoo·FRED 접속이 막혀 있으면 설정의 **데모 데이터 사용**을 체크해 화면부터 확인하세요.
- 데모 데이터는 160거래일마다 유의 팩터가 바뀌도록 만든 합성 데이터라, 모델이 국면 전환을 잡아내는지 볼 수 있습니다.

## 2. 하루 한 번 자동 실행

```bash
python run_daily.py              # 4개 지수 모두, 마지막으로 저장한 설정으로 갱신
python run_daily.py --target KOSPI
```

- **Windows 작업 스케줄러**: 기본 작업 만들기 → 매일 07:30 → 프로그램 `C:\...\factor_factory\.venv\Scripts\python.exe`, 인수 `run_daily.py`, 시작 위치 `C:\...\factor_factory`
- **macOS/Linux cron**: `30 7 * * 1-5 cd /path/factor_factory && .venv/bin/python run_daily.py`

07:30 KST 실행이면 전일 미국 마감과 FRED 데이터가 반영된 상태에서 KOSPI 전일분까지 계산됩니다.

## 3. 모델 구조

| 단계 | 내용 |
|---|---|
| 팩터 팩토리 | 글로벌 주식(S&P·나스닥·SOX·닛케이·항셍·상해), VIX, 달러인덱스·원/달러·엔/달러, WTI·금·구리·비트코인, 미 10년·2년 금리, 장단기 금리차, 기대인플레, 하이일드 스프레드, 기술적(모멘텀 5·20일, 단기반전, 실현변동성 변화) |
| 시차 정렬 | 레벨을 대상 지수 날짜에 as-of 정렬한 뒤 변화율 계산. KOSPI 기준 미국·환율·코인은 **전일 값**만 사용(미래정보 차단) |
| 롤링 회귀 | 최근 N일(기본 252일) 표준화 OLS, **Newey-West(HAC)** 표준오차 |
| 상관 제거 | 종속변수와 상관이 큰 순서로 채택, 기존 팩터와 \|ρ\| ≥ 0.8이면 제외 |
| t-검정 | 후진제거: 기준 미달 팩터를 하나씩 빼며 재추정 |
| 다중검정 보정 | BH(FDR, 기본) / \|t\| ≥ 3 / 없음 |
| F-검정 | 남은 팩터 전체의 HAC Wald F 검정 통과 시에만 그날 모델 '유효' |
| 가중치 | 당일 \|t\| 비중 → EWMA(반감기 10일) 평활 |
| 표본외 검증 | 전일까지의 평활 모델로 당일을 계산 → 표본외 R², 방향 적중률 |

### 다음 1주 전망 (상단 패널)
- **질문**: 오늘 종가 기준으로, 다음 5거래일 뒤 지수가 오를까?
- **신호**: 오늘 장 마감 시점에 이미 아는 값만 씁니다. 지수 1주·1개월·3개월 수익률, 200일선 이격, 52주 고점 대비 낙폭, 20일 변동성, VIX 레벨·1주 변화, 하이일드 스프레드(또는 HYG), 미 10년물 1개월 변화, 장단기 금리차, 달러·원/달러·반도체·구리·유가의 1개월 변화, (한국 지수) S&P500 1주 수익률.
- **학습**: 최근 3년(756거래일) 롤링 회귀입니다. 5일 수익률이 확정된 날까지만 학습하므로 미래 정보가 섞이지 않습니다. 겹치는 수익률이라 Newey-West 시차는 10, BH 보정을 적용합니다.
- **상승 확률** = 정규분포 가정에서 P(5일 수익률 > 0)입니다. 68% 범위는 ±1σ입니다.
- **자기 채점**: 과거 약 2년을 서로 겹치지 않는 주 단위로 나눠, '항상 상승(또는 다수 방향)' 찍기보다 적중률이 통계적으로 높았는지 이항검정합니다. 결과에 따라 신뢰도를 '참고 가치 있음 / 약한 신호 / 참고용(우위 없음)'으로 표시합니다.
- 일주일 방향은 원래 맞히기 어렵습니다. 대부분의 기간에 '참고용'이 나오는 것이 정상이니, 신뢰도 표시를 확률 숫자보다 먼저 보세요.
- 설정에서 전망 기간을 2주·1개월로 바꿀 수 있습니다. 기간이 길수록 추세·밸류 신호가 작동할 여지가 조금 커집니다.

### 개장 전 예측 모드 (기본)
- 대상 지수 장이 열리기 **전에 이미 마감된 시장 정보만** 씁니다.
  - KOSPI·KOSDAQ: 간밤 미국장(S&P500·SOX·VIX·금리·유가 등), 원/달러·달러인덱스, 전일 아시아장
  - S&P500·NASDAQ100: 당일 아시아장(닛케이·항셍·상해), 전일 미국장
- 상단 카드에 **다음 세션 예상 등락·상승확률·근거 팩터(간밤 변화 → 예상 기여)**를 보여줍니다.
- 07:30 갱신에서 한국 지수가, 15:40 갱신에서 미국 지수가 계산됩니다.
- 종가 대비 종가 기준 예상입니다. 시초가에 이미 반영되는 부분(갭)이 대부분이라 "장 방향 브리핑"용이지, 시초가 매매 신호는 아닙니다.
- 장중에 실행하면 아직 끝나지 않은 당일 봉은 자동으로 제외합니다.

### 설명 모드 vs 예측 모드
- **설명(explain)**: 같은 날(또는 시차상 직전) 팩터 변화로 당일 수익률을 설명. "오늘 시장을 움직인 게 뭐였나" 분석용.
- **예측(predict)**: 팩터를 1거래일 더 늦춰 내일 수익률을 예측. 일간 데이터에선 유의한 팩터가 드물고, 보정 없이 돌리면 우연히 유의한 팩터가 자주 나옵니다(데모로 확인 가능). 예측 모드에선 BH나 \|t\|≥3 보정을 권장합니다.

### 네트워크가 불안정할 때
- Yahoo에서 일시적으로 빠진 티커는 한 번 더 받아오고, 그래도 실패하면 이전 캐시를 씁니다.
- FRED는 4개 시리즈를 병렬로 받고 시리즈당 최대 2회 시도합니다. 전부 실패해도 약 30초 안에 넘어갑니다.
- FRED를 못 받으면 **미 2년물 → 2년물 금리선물(2YY=F)**, **하이일드 스프레드 → HYG ETF**로 자동 대체합니다.
  HYG는 가격이라 스프레드와 부호가 반대입니다(스프레드 확대 = HYG 하락).
- 업데이트 중에 콘솔을 닫거나 Ctrl+C를 누르면 진행 중인 작업이 저장되지 않습니다.

## 4. 주의사항

- 매일 유의성으로 팩터를 고르는 방식은 데이터 마이닝 위험이 큽니다. **표본외 R²가 꾸준히 0 이상인지**를 기준으로 판단하세요.
- FRED의 ICE BofA 하이일드 스프레드는 라이선스 문제로 최근 약 3년치만 제공됩니다. 이 팩터가 포함되면 공통 표본도 그 기간으로 줄어듭니다.
- 원/달러(KRW=X) 등 야후 환율의 날짜 기준은 런던·뉴욕 시간이라, KOSPI·KOSDAQ 대상에선 보수적으로 전일 값을 씁니다.
- 투자 판단의 보조 자료이며 결과를 보장하지 않습니다.

## 5. 팩터 아카이브 — 새 독립변수 추가·관리 원칙

웹/로컬 상단의 **팩터 아카이브** 탭에서 모든 팩터의 성적표를 볼 수 있습니다.

### 추가 절차
1. **근거 먼저**: `config.py`의 `FACTORS`에 `why`(왜 지수를 움직이는지 한 줄)를 반드시 적습니다. 근거가 없으면 등록하지 않습니다.
2. **후보로 투입**: `status="candidate"`, `added="날짜"`로 넣습니다. 모델에 바로 들어가며, 여러 변수를 동시에 검정하는 문제는 BH 보정이 통제합니다.
3. **성적 평가**: 아카이브에서 지수별 채택률·부호 일관성·중복(상관제거) 비율을 봅니다. 저장된 500거래일 롤링 결과라 신규 후보도 첫 실행부터 성적이 나옵니다.
4. **승격/은퇴**: 한 지수라도 '핵심·간헐적 유효'면 `status="core"`로 승격합니다. 모든 지수에서 '휴면'이면 `status="retired"`로 바꿉니다. 은퇴한 변수는 계산에서 빠지지만 기록은 남습니다.

### 금지 규칙
- **선형결합 금지**: 구리와 금이 모두 개별 팩터인데 '구리/금 비율'을 또 넣으면 회귀가 깨집니다. `config.registry_problems()`가 자동으로 점검하고, 아카이브 상단에 경고를 띄웁니다.
- **대상과 같은 자산 금지**: 예를 들어 S&P 500을 설명하는 데 S&P 500 ETF를 쓰지 않습니다. 이런 팩터는 `TARGETS[...]["exclude"]`에 넣습니다.

### 등록 형식
```python
"EWY": _f("yahoo", "EWY", "US", "logret", "한국 ETF(EWY)", "주식",
          "간밤 미국 시장 참가자가 본 한국 주식", status="candidate", added="2026-10-28"),
# 파생 팩터: 두 티커의 비율(ratio) 또는 차이(spread)
"VIXTERM": _f("derived", "VIX-VIX3M", "US", "diff", "VIX 기간구조", "변동성", "단기 공포 역전 = 패닉",
              op="spread", a="^VIX", b="^VIX3M", unit="pt", status="candidate", added="2026-10-28"),
```
- `source`: `yahoo` | `fred` | `derived`
- `region`: 마감 순서 판정용. `ASIA` < `EU` < `US`·`FX` < `CRYPTO`
- `transform`: 가격은 `logret`, 금리·스프레드·지수 레벨은 `diff`
- `unit`: 화면 표시 단위. `%` | `bp` | `pt`

## 7. 보안·성능

- POST 요청 CSRF 토큰 검증, CSP·X-Frame-Options 등 보안 헤더, 입력값 화이트리스트·범위 검증, 파라미터 바인딩 SQL
- 기본 바인딩 `127.0.0.1` (외부 공개 시 `FACTOR_HOST`, `FACTOR_SECRET_KEY` 환경변수 설정)
- 창별 Gram 행렬을 한 번만 계산해 후진제거를 가속, scipy 특수함수로 p값 계산 → 지수당 500거래일 약 1.5초
- DB 연결은 매 작업마다 닫고, 업데이트는 동시에 1개만 실행
